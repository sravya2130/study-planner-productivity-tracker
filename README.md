# Study Planner & Productivity Tracker

A Python-based desktop application designed to help students manage study tasks, track study time, and visualize weekly productivity.

## Features

- Add and manage study tasks
- Set deadlines for tasks
- View all tasks
- View completed tasks
- Mark tasks as completed
- Delete tasks
- Log study hours by category
- View total tasks, completed tasks, and study hours
- Generate weekly study analytics
- Visualize study hours using bar charts
- Simple desktop GUI built with Tkinter

## Technologies Used

- Python
- Tkinter
- JSON
- CSV
- Matplotlib
